# Plan VII: Mainnet v2 (human checkpoint), `current` flip, SDK major release

**Sprint goal:** Stellar contracts run on soroban-sdk 27 as versioned v2 deployments whose addresses every consumer resolves from contracts.json.
**Worktree:** false — sequential waves share `node_modules`, `target/` and `dist/` build caches on one checkout, and Plans VI/VII need the deployed registry state of that same checkout.
**This plan delivers:** the mainnet v2 deployment performed by the user with their own signing keys at an explicit checkpoint, the registry and every README updated with the mainnet v2 ID, the Railway runbook completed, and the coupled `@attestprotocol/stellar-contracts` + `@attestprotocol/stellar-sdk` major prepared via changesets. Per D-06 nothing in task I runs unattended.

## Tasks

### I. [CHECKPOINT: HUMAN] Mainnet deployment by the user

- **Files:** `contracts/stellar/bindings/src/contracts.json` (written by `deploy.sh` when the user runs it), `contracts/stellar/deployments.json` (regenerated by `deploy.sh`; unchanged in content while `mainnet.current` is v1)
- **Read first:** `contracts/stellar/deploy.sh`, `contracts/stellar/readme.txt` "Deploy to Mainnet", `apps/horizon/scripts/mainnet/README.md` lines 40-50 and 290-300, EXECUTION.md wasm size from Plan I
- **Action:** Per D-06 the executor prepares, then stops.
  1. Build fresh: `cd contracts/stellar && stellar contract build && stellar contract optimize --wasm target/wasm32v1-none/release/protocol.wasm`; record the sha256 of the optimized wasm.
  2. Write the exact command for the user into EXECUTION.md and return it to the orchestrator as a `## HUMAN CHECKPOINT` block:
     ```
     cd contracts/stellar
     ./deploy.sh --protocol --version v2 --network mainnet \
       --rpc-url <user's mainnet RPC, e.g. https://soroban-rpc.mainnet.stellar.gateway.fm or https://mainnet.sorobanrpc.com> \
       --network-passphrase "Public Global Stellar Network ; September 2015" \
       --source <user's mainnet identity> \
       --fee 120000000 \
       --initialize --yes
     ```
     with the notes: the fee is the value used for the v1 mainnet deploy (`readme.txt`); `--initialize` sets the admin to the source identity's address; the script writes `mainnet.v2` and leaves `mainnet.current = "v1"`.
  3. STOP. Do not run the command. Do not proceed to task II until the orchestrator relays the user's explicit go-ahead and the user has run the command (or supplied the resulting ID, tx hash, ledger and wasm hash to enter by hand with the same `jq` shape `deploy.sh` uses).
  4. On resume, verify `jq .mainnet.v2 contracts/stellar/bindings/src/contracts.json` is complete and `stellar contract invoke --id <mainnet v2 id> --network mainnet --source <any funded identity or --sim-only if supported> -- get_dst_for_attestation` simulates successfully (read-only).
- **Done when:** EXECUTION.md contains the checkpoint block and the orchestrator has recorded the user's go-ahead; `jq -r '.mainnet.v2.id' contracts/stellar/bindings/src/contracts.json` prints a 56-char `C…` ID different from `CBUUI7WKGOTPCLXBPCHTKB5GNATWM4WAH4KMADY6GFCXOCNVF5OCW2WI`; `jq -r '.mainnet.v2.sdk'` = `27.0.6`; `jq -r '.mainnet.current'` = `v1`; `jq -r '.mainnet.v1.id'` unchanged.
- **Covers:** D-01, D-06, GOAL mainnet deploy
