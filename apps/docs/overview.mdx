## What is AttestProtocol?

On-chain attestations with BLS delegation and payment-gated verification. Issue credentials in minutes.

## Quick Example

```typescript
import { StellarAttestationClient } from '@attestprotocol/stellar-sdk';

const client = new StellarAttestationClient({
  rpcUrl: 'https://soroban-testnet.stellar.org',
  network: 'testnet',
  publicKey: 'GXXX...'
});

// Create attestation
await client.attest({
  schemaUid: schemaUid,
  value: JSON.stringify({ verified: true, level: 'basic' }),
  options: { signer }
});
```
