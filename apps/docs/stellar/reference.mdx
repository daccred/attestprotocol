## Installation

```bash
npm install @attestprotocol/stellar-sdk @stellar/stellar-sdk
```

## Client Initialization

```typescript
import { StellarAttestationClient } from '@attestprotocol/stellar-sdk';

const client = new StellarAttestationClient({
  rpcUrl: string,           // Soroban RPC URL
  network: 'testnet' | 'mainnet',
  publicKey: string,        // Your Stellar public key
  contractId?: string,      // Optional: custom contract ID
  allowHttp?: boolean       // Allow HTTP (dev only)
});
```

## Core Methods

### createSchema

```typescript
await client.createSchema({
  definition: string,    // Schema structure
  revocable?: boolean,   // Default: true
  resolver?: string,     // Optional resolver contract
  options?: { signer, simulate }
})
```

### attest

```typescript
await client.attest({
  schemaUid: Buffer,
  value: string,           // JSON-encoded data
  subject?: string,        // Defaults to attester
  expirationTime?: number,
  options?: { signer, simulate }
})
```

### revoke

```typescript
await client.revoke({
  attestationUid: Buffer,
  options?: { signer, simulate }
})
```

### getSchema

```typescript
const result = await client.getSchema(uid: Buffer)
```

### getAttestation

```typescript
const result = await client.getAttestation(uid: Buffer)
```

## BLS Delegation

### generateBlsKeys

```typescript
const { publicKey, privateKey } = client.generateBlsKeys()
```

### registerBlsKey

```typescript
await client.registerBlsKey(publicKey: Buffer, options?: { signer })
```

### getBlsKey

```typescript
const blsKey = await client.getBlsKey(attester?: string)
```

### attestByDelegation

```typescript
await client.attestByDelegation({
  attester: string,
  schema_uid: Buffer,
  subject: string,
  value: string,
  nonce: bigint,
  deadline: bigint,
  expiration_time: bigint | undefined,
  signature: Buffer
}, options?: { signer })
```

### revokeByDelegation

```typescript
await client.revokeByDelegation({
  attestation_uid: Buffer,
  schema_uid: Buffer,
  subject: string,
  revoker: string,
  nonce: bigint,
  deadline: bigint,
  signature: Buffer
}, options?: { signer })
```
